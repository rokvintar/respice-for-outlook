Respice for Outlook

An Outlook add-in that makes you look once more before a risky email goes out.

  • External recipients
  • Mailing lists
  • More than X recipients
  • Replies to more than the sender

Each rule can be switched on or off. Every rule checks To, Cc and Bcc.

Privacy

Recipients are checked inside Outlook. Settings are stored in your own mailbox. Nothing is sent to any server, and there is no analytics or tracking.

Install

  1. Download manifest.xml
  2. Go to aka.ms/olksideload → My add-ins → Add a custom add-in → Add from File → select the file.
    No "Add a custom add-in" option? Your IT blocks user add-ins. Ask them to deploy the manifest.
  3. Restart Outlook.

Settings: open any message → Apps → Respice settings.

Mobile shows the warning bar only.
